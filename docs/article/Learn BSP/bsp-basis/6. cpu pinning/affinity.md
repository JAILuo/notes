# 1. introduction

工作、看技术文章、刷B站的时候，常常都能听说什么绑核、affinity、让某个游戏运行在某个处理器核心上、什么大小核/能效核.....

很多都听不懂（我是小白）......也有可能是我懂，但我不理解他们说的这么高级的名词是啥😅😅

所以我还是按照自己的感觉来学吧......所以，会有很多大家看起来弱智的问题......

我的几个疑问或者理解：

1. 因为有了 **everything is state machine** 的理解，我知道多核处理器的每一个 core，都会有自己的 regs，然后再加上共有的 memory 作为单核的状态。那我的问题是：**“大家说的绑核，在 Linux 上，让某个进程（还是线程呢，或者说 task）运行在指定的处理器核心上是怎么做到的呢？如果又要改变某个核心运行的 task，怎么做呢？**“

    我觉得这应该是一个无关于是否有 OS 的问题？

    换句话说，哪怕是在什么 RTOS：FreeRTOS、Zephyr、QNX 应该也是可以实现的指定的核心运行指定的任务的。**但是光知道个接口我觉得还不够，底层一点硬件咋做的呢？配 affinity？为啥配 affinity 能够实现呢？**值得思考......

    欸突然想到的是，bare-metal 裸机应该也是能够做到的类似的效果吧？

2. 另外，能不能做到把某些 interrupt handler 指定放到某个 core 上做呢？咋做到的呢？

3. 我一直想问的是，为啥超过温度，手机就会限频呢？这是由 vendor 决定的，还是手机厂商 OEM 决定的呢？
